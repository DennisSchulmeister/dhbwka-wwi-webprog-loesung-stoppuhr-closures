# Webprogrammierung / Lösung / Stoppuhr mit Closures

Dies ist die **Musterlösung** zur Aufgabe „Stoppuhr mit Closures" aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *JavaScript*.

Eine Stoppuhr wird unter Verwendung von Closures implementiert.

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
